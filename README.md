# Portafolio de Marco Berrios Vera

Sitio personal con mi perfil, habilidades y proyectos como Técnico Informático con mención en Ciberseguridad.


## Tecnologías

- Next.js (App Router)
- React
- Tailwind CSS
- Desplegado en Vercel

## Cómo ejecutarlo en tu computador

```bash
npm install
npm run dev
```

Luego abre http://localhost:3000 en el navegador.

## Estructura

- `src/app`: página principal y configuración general del sitio.
- `src/components`: encabezado, tarjeta de perfil y secciones de habilidades, proyectos y contacto.
- `public`: imágenes.
